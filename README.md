# Koleksi Aplikasi

## CandleLab — aplikasi desktop

**CandleLab** adalah aplikasi desktop offline untuk eksperimen probabilitas warna candlestick berikutnya. Tersedia grafik OHLC, model Bayesian yang transparan, backtest walk-forward, impor/ekspor CSV, serta pencatatan prediksi terkunci dan hasil aktualnya. Ini adalah alat eksperimen, bukan kepastian atau rekomendasi finansial.

Source dan panduan menjalankan aplikasi Windows/Linux/macOS berada di [`CandleLab/`](CandleLab/). Lihat [CandleLab/README.md](CandleLab/README.md) untuk launcher desktop, format CSV, metode, pengujian, dan cara membuat `CandleLab.exe`.

## Aplikasi Android

Proyek **ToxiFlow**, aplikasi pencatat pemasukan dan pengeluaran yang bekerja secara offline, berada di folder [`ToxiFlow/`](ToxiFlow/). Panduan penggunaan, privasi, dan cara membuat APK tersedia di [ToxiFlow/README.md](ToxiFlow/README.md).

Proyek **DocScan Toxi** berada di folder [`DocScanToxi/`](DocScanToxi/). Aplikasi ini memindai atau mengimpor dokumen, menyimpannya sebagai PDF/JPG, serta mengekstrak teks. Panduan instalasi, penggunaan, persyaratan, dan pembuatan APK tersedia di [DocScanToxi/README.md](DocScanToxi/README.md).

File `splash_screen.py` dan `splash_logo.png` tetap dipertahankan untuk aplikasi desktop lama. CandleLab adalah proyek desktop baru yang terpisah dan tidak mengubah splash tersebut. Splash screen Android menggunakan logo yang sama dan menyesuaikan nama serta versi untuk DocScan Toxi.
