## Informasi dan penggunaan

Aplikasi memproses foto, dokumen, hasil OCR, dan perubahan yang Anda pilih untuk menyediakan fitur pemindaian, penyuntingan, penggabungan, ekspor, dan berbagi. Dokumen aplikasi dan salinan kerja/cache disimpan secara lokal pada perangkat; salinan yang Anda ekspor disimpan pada lokasi/penyedia yang Anda pilih. Beberapa operasi menggunakan file sementara lokal. Aplikasi tidak memerlukan akun atau server backend milik penerbit untuk fitur-fitur ini. [PENERBIT: VERIFIKASI KEMBALI TERHADAP BUILD RILIS DAN SEMUA SDK.]

Pemindai otomatis dan pengenalan teks menggunakan Google ML Kit. Menurut [Google ML Kit Terms & Privacy](https://developers.google.com/ml-kit/terms), input dan hasil pemrosesan ML Kit diproses di perangkat dan tidak dikirim ke server Google, tetapi ML Kit dapat menghubungi server Google untuk pembaruan, perbaikan dan informasi kompatibilitas, serta mengirim metrik kinerja dan penggunaan API kepada Google. Pemindai otomatis memakai Google Play Services dan komponennya dapat diunduh. [PENERBIT: TELAAH SELURUH JENIS DATA DAN TUJUAN PEMROSESAN GOOGLE UNTUK VERSI SDK YANG DIGUNAKAN, SERTA KEBIJAKAN YANG BERLAKU.]

Saat Anda memakai aplikasi kamera, pemilih/penyedia file, penyimpanan cloud, atau aplikasi lain untuk berbagi, layanan yang Anda pilih dapat menerima atau memproses file sesuai pengaturan dan kebijakan mereka. ## Penyimpanan dan penghapusan

Anda dapat menghapus dokumen dalam aplikasi. Menghapus aplikasi menghapus data aplikasi lokal; cadangan Android untuk aplikasi ini dinonaktifkan. Ekspor file penting terlebih dahulu jika ingin menyimpannya. File yang sudah diekspor, disimpan di penyedia lain atau dibagikan tidak otomatis terhapus saat aplikasi dihapus; kelola dan hapus di lokasi/penerima masing-masing. Metrik yang diproses pihak ketiga tunduk pada kebijakan dan masa retensi mereka. [PENERBIT: TENTUKAN KEBIJAKAN RETENSI DAN HAK PENGGUNA YANG BERLAKU.]
